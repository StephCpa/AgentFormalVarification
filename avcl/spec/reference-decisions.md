# 参考实现决策

## ADR-001：先建立内存事务语义

所有正常写入在同一 `RLock` 内完成。prepare 先在临时账户字典检查全部预算，再一次提交操作、许可、批准占用、业务键和审计事件。该选择让并发交错与状态语义可先验证；它不提供 WAL、崩溃原子性或多进程协调。持久实现沿用详细设计的 PostgreSQL 路线，不把内存保存到 JSON 当作事务数据库。

## ADR-002：请求绑定使用受限编码

请求边界禁止 JSON 数字，金额为无符号十进制整数字符串；对象键仅 ASCII、字符串严格 UTF-8、重复键拒绝、键序排序、无空白紧凑输出、64 KiB 上限。摘要包含用途域和 NUL 分隔。当前实现不是完整 RFC 8785 JCS，不能与其他规范化实现互认摘要。完整请求 schema 固定后需给出跨语言测试向量。

纯谓词编译器接受宿主 AST（Int 常量为 Python 整数）或 IR v0.2 JSON（Int 常量、范围和规模均为规范十进制字符串）。IR 使用独立版本和摘要域；Option 显式编码 None/Some，Set 按编码排序且拒绝重复元素。当前统一到单谓词生成门禁，完整合约模块的 R13 工作继续推进。

## ADR-003：外部效果由独立对象维护

模拟服务在自身锁内检查订单并写入幂等结果，实际成本只从远端效果表求和。内核账本不作为 oracle。观察是受信适配器入口，当前只有结构校验和绑定校验，没有签名认证。模拟 `send` 接受已准入 Operation 是宿主协议，不是能力安全接口。

## ADR-004：终态不抹除费用与争议

`final_cost` 与 `terminal_effect` 同时成立才能释放剩余额度。累计成本递减或终态冲突时保留原账本并记争议，等待人工核对，不随意选一个冲突声明覆盖事实。可确定的超界新增费用记录到账本并冻结危险动作；`Disputed` 对普通回执是粘性的。尚无争议解除权限/API。

## ADR-005：三类去重身份分开

`client_request_id` 约束同一主体的 prepare 重试；`business_key` 约束逻辑业务动作；`operation_id` 约束远端效果。业务键冲突不能靠新客户端请求键绕过。当前即使准入前取消，也保留业务键墓碑，不自动发起替代操作；明确授权的替代链留待后续实现。

## ADR-006：证据保留失败与边界

每次验证写新的目录，保存正常模型和两个错误模型。源码摘要允许把证据准确绑定到实现版本。Lean 结果只对抽象转移系统有效；模型回放只覆盖枚举边及其代表历史。所有功能状态以实现矩阵为准，未实现项不因某个局部证明通过而升级。

## ADR-007：同一 IR 生成检查产物

参考解释器递归求值 IR；生成器将同一 IR 转换为封闭指令集的栈式检查器，用前向跳转实现短路与 If。加载器依据可信 IR 重新生成并逐项比较指令，不只比较声明的摘要。内核准入执行生成检查器，许可冻结语义摘要。这个过程不是编译器机械正确性证明，仍须独立后端一致性测试。

## ADR-008：候选包与证据状态分离

未签名候选包不承担完整政策发布身份；加载需要宿主提供独立可信的 IR 摘要。文件摘要负责完整性，不能证明发布者身份。有限域枚举只对完整且不超过上限的声明输入域给出 BoundedChecked；过大、未枚举的域给出 Unknown，全部拒绝给出允许动作存在性 Violated。报告不改变执行授权，运行求值另记 RuntimeSatisfied/Violated/Unknown。

## ADR-009：合约发布使用独立宿主授权域

单谓词候选包保留原定位；合约发布另用 v0.3 HMAC 封套。需求审阅集合、获准运行检查和共同允许见证是签发输入，不能从某个单项绿色报告自动推定。HMAC 密钥只在本轮宿主内存，生产身份与持久签发不是本次保证。

## ADR-010：政策切换不迁移在途事实

政策激活与派发用同一个参考锁，并严格增加版本与 epoch。旧 Prepared 需显式取消；已准入和 Unknown 保留原快照。冻结条款及所依赖的假设不能由普通更新修改。新限额不足以覆盖既有承诺时整次更新失败；禁止为让更新通过而删去承诺或恢复旧 epoch。

## ADR-011：工作流分支使用资源交集与效果并集

资源合流保留所有分支都仍可用且类型相同的绑定，效果覆盖所有分支。当前不使用路径求解器放宽这个规则。丢弃局部许可只做仿射弱化，必须保留账本预留，显式 Abort 才调用未派发取消事务。

## ADR-012：工作流结束不代表操作终局

Dispatch 只准入，Send 才通过受控适配器发出原操作。Finished/Halted 描述程序执行，操作状态和资金状态另列。错误回执和传输异常不建立无效果证明；保留操作列表和承诺，允许宿主核对。工作流引用不能授予权限，候选计划仍需每步经过内核门禁。
